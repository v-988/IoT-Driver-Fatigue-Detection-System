# IoT-Based Driver Fatigue Detection System

IoT-based driver fatigue detection system using MPU6050 and IR eye blink sensor to detect driver drowsiness and trigger real-time buzzer alerts.

## Components Used
- Arduino UNO
- MPU6050 Sensor
- IR Eye Blink Sensor
- Buzzer

## Features
- Real-time fatigue detection
- Eye blink monitoring
- Head movement detection
- Buzzer alert system

## Output
- Detects driver drowsiness
- Activates buzzer alerts
- Displays sensor data in Serial Monitor
